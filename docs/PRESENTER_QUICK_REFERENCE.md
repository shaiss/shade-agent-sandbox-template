## 🎮 New Feature: Nonce Auto-Increment Toggle

**When ENABLED (default):**
- Multiple chains work seamlessly
- Can add 5, 10, or more chains
- One click updates all chains

**When DISABLED (for education):**
- Shows NEAR's replay attack protection
- Second transaction may fail with nonce error
- Perfect teaching moment about security

**Demo Script:**
1. "Let me show you something cool about security..."
2. *Toggle OFF nonce increment*
3. "Watch what happens when we disable auto-increment"
4. *One chain succeeds, one fails*
5. "NEAR protects against replay attacks! Now watch this..."
6. *Toggle ON*
7. "With proper nonce management, unlimited chains work!"
